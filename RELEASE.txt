Frecuencia Cero V24 — Acceso controlado e invitaciones por enlace

- Gate obligatorio para navegadores sin membresía Firebase verificada.
- La URL pública no concede acceso y no presenta un botón de solicitud sin invitación.
- Enlace general: invitado selecciona función y solicita; el propietario aprueba. Reutilizable.
- Enlace con función preasignada: invitado recibe un rol sugerido, solicita y espera aprobación. Token de un solo uso, 7 días.
- QR sigue sirviendo para vincular dispositivos adicionales a un integrante autorizado.
- El catálogo estático se retiró del HTML público actual; las letras se cargan desde Realtime Database tras autorización.
- Se conserva UID propietario y band ID actuales.
